# Nexus Software Website

A responsive static website built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. In the repository, open Settings → Pages.
4. Choose Deploy from branch → main → /root.
5. Save and wait for GitHub Pages to publish.

## Before publishing
- Replace the placeholder email and phone number in `index.html`.
- Replace the WhatsApp number in the `wa.me` link.
- Connect the contact form to Formspree, Google Forms, or your own backend if you want real submissions.
